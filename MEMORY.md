## Project snapshot
- **Game:** Speed Riddlemaster, a neo-Sherlock / Disco-Elysium-vibe riddle website game.
- **Core loop:** 10 random riddles, 20 s each, 3 lives. Wrong or late answer = lose a life. Lose a life = "resurrected". Lose all 3 = "You've been found, Detective." Finish all 10 = "Case solved!"
- **Tone:** friendly, gamified, funny. Praise ("Good job, Detective") on correct answers.
- **Answers:** one word only; reasonable misspellings are accepted.
- **Riddle sourcing:** existing/classic riddles, but not the super-famous ones (so they're not trivially guessable).

## Decisions (made in PRD draft; confirm with Danyal)
- Wrong answer or timeout both cost exactly 1 life; the riddle is spent and the game moves on (no retry on the same riddle).
- Riddles drawn from a curated JSON bank (target ≥100, min 60 for launch); no live LLM generation at play time. LLM-assisted additions only post-launch and human-reviewed.
- Fuzzy matching: edit-distance scaled by answer length (1–3 letters exact, 4–6 → 1 typo, 7+ → 2 typos), plus `accepted[]` synonyms and `reject[]` lists to stop typos landing on other real words (e.g. cold/gold).
- Scoring: 100 base + up to 100 time bonus + streak bonus (cap +50); Detective Rank titles; local personal best; Wordle-style emoji share card.
- Client-side only, no accounts/backend. Timer pauses on feedback screens and starts after riddle text is visible.
- No hints/power-ups in v1 (post-launch idea).

## Key takeaways / learnings
- The user's phrase "you've been found Detective" is ambiguous (maybe "found out"/"found dead"); PRD uses it as written with comedic framing — flagged as open question.
- Fuzzy matching is the main fairness risk: needs a unit-tested typo corpus and playtest logging.
- Disco Elysium inspiration should be mood/structure only; original assets to avoid IP risk.

- **Accepted-answer lists are a fuzzy-match hazard.** A synonym like "globe" (for map) or "brain" (for mind) can fuzzy-match another riddle's answer (glove, rain). The cross-riddle test in `tests/matcher.test.js` catches this; re-run it whenever riddles/accepted lists change.
- 3-letter answers (ton, map, egg, key) are exact-match only; "tounge"-style common misspellings go in `acc`.
- Browser pane can't run scripts for `file://` outside the project; use `node serve.js` (config in `.claude/launch.json`).
- Implementation choices beyond the PRD: timer starts 650 ms after the card slides in and uses clamped frame deltas (backgrounded tab doesn't burn time); multi-word wrong answers nudge without costing a life; if a multi-word answer contains the right word ("it's a towel") it's accepted; Next button ignores clicks for 450 ms after feedback so a held Enter can't skip it.

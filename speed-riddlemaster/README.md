# Speed Riddlemaster

Ten riddles. Twenty seconds each. Three lives. One very smug detective (you).

## Play
Open `index.html` in a browser, or serve it locally:

```bash
node serve.js        # http://localhost:5173
```

No build step, no dependencies. Vanilla HTML/CSS/JS. Music starts after your first click or tap (browser rule); the ♫ and ♪ buttons toggle music and sound effects.

## Test
```bash
node tests/matcher.test.js
```
Checks the riddle bank's data and the forgiving-spelling matcher (typos accepted, look-alike real words such as cold/gold rejected, no riddle's accepted answers leaking into another).

## Human playtest
Open `http://localhost:5173/?playtest`. It records every riddle (outcome, seconds, each guess typed) and shows a 1–5 rating panel after each game; data stays in the browser. Follow [playtest/PLAYTEST.md](playtest/PLAYTEST.md), then:

```bash
node playtest/analyze.js playtest/session-1.json playtest/session-2.json
```

`playtest/sample-data.SIMULATED.json` is bot-generated data used only to test the analysis script. It is not real feedback.

## Layout
| Path | What it does |
|---|---|
| `index.html` | All screens, inline SVG icons and rank glyphs |
| `css/style.css` | Neo-noir look: painted backdrop, rain, fog, case-file paper, stamps, mood changes per screen |
| `assets/scene.svg` | Painted-look London-at-night backdrop (generated by `tools/build-scene.js`) |
| `assets/detective.svg` | Title-screen hero |
| `assets/spot-*.svg` | Win / lose / resurrection illustrations |
| `assets/favicon.svg` | Tab icon |
| `js/riddles.js` | Riddle bank (59 riddles, 3 difficulty tiers) |
| `js/matcher.js` | Pure answer matcher: normalise, plurals, edit-distance by word length, `rej` blocklist |
| `js/copy.js` | Narrator lines: praise, fails, resurrection, ranks |
| `js/music.js` | Procedural noir-jazz score (bass, keys, brushes, muted trumpet, rain) with calm / play / urgent / win / lose moods |
| `js/game.js` | Game flow, timer, lives, scoring, sound effects, share card, playtest mode |
| `playtest/` | Playtest kit and analysis script |
| `tools/` | `build-scene.js` (regenerates the backdrop), `simulate-playtest.js` (bot data for testing the analyzer) |

Add `?debug` to the URL to expose `window.SR_DEBUG` (used for automated checks).

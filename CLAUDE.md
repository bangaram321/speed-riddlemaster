Context

I would like to create a website game where you can be on riddles! 

I want it to look super neo-sherlock holmesy, almost like Disco Elysium vibes visually. 

I'd like the user to be given 10 randomly generated riddles but certainly utilise riddles that have been created already or are common but not seriously common so that they aren't easy to guess. 

they need to receive praise and good job detective or something when they get one right

simple - 10 riddle format, but you only have 20 seconds to answer. You have 3 lives if you don't answer in time, or get it wrong then you lose a life. 

When you die, you've been resurrected

When you run out of all your lives, you've been found Detective. 

If you win the game, you've solved the case!

I'd like this website to be friendly and gamified. 

I want people to enjoy and laugh when playing this game. 

Misspelling doesn't penalise you if it's a reasonable misspell of the answer. Only one word answers or riddles that require one word. 

Create a product requirement document for this game. 

The game will be called Speed Riddlemaster

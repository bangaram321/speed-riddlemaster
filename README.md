# Speed Riddlemaster

A neo-Sherlock-Holmes riddle game for the browser. Ten riddles, twenty seconds each, three lives, and one very smug detective (you).

- **The game:** [`speed-riddlemaster/`](speed-riddlemaster/). Run `node serve.js` inside it and open http://localhost:5173 (or just open `index.html`). See its [README](speed-riddlemaster/README.md).
